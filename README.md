# AI-SMS — Human-in-the-Loop Decision Support Prototype

Final Year Project I. Advisory only. Human decision mandatory.

## Setup

1. Install Python 3.10+
2. `pip install -r requirements.txt`
3. Place `AI_SMS_Starter_Datasets.xlsx` inside `data/`
4. `python init_db.py`
5. `python app.py`
6. Open http://127.0.0.1:5000

## Core Rule

AI advises only. Human approval is mandatory before any final decision or action.

## Project I Scope

- Seven-stage workflow
- Rule-based / template-driven logic
- Synthetic data only
- No real AI model (reserved for Project II)
